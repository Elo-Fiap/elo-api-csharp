== (c) Dado legado: gravado direto no SQLite, sem passar pela API ==
sqlite3: UPDATE Respostas SET Observacao = 'CPF 123.456.789-00, vizinha diabética' ...
No banco, o dado está lá, em texto puro:
demo-c-1794971837|CPF 123.456.789-00, vizinha diabética

Agora a API lê a mesma resposta (GET /api/chamadas/2/respostas):
{
  "idLocal": "demo-c-1794971837",
  "observacao": "CPF ***.456.***-00, vizinha [dado de saúde oculto]"
}
A guarda de saída (resposta HTTP) barrou o dado antes de ele sair. Esse é o evento vermelho de "resposta da API".
